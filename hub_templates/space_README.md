# BeamDial

Paste a prompt and see which `reasoning_effort` BeamDial would pick for Beam, and why. The router runs in your browser: nothing is sent anywhere. The Results tab shows the study behind it: 410 graded tasks at all five levels.

- Code: https://github.com/OWNER/beamdial
- Data: https://huggingface.co/datasets/HFUSER/beamdial-v0.1
