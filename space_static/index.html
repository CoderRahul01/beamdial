Pay for max thinking only when it helps.

Beam has five reasoning levels. On standard math and code, low matches max for about half the tokens. BeamDial picks the level per request, escalates when a prompt looks hard, and lets you measure the gap on your own prompts.

Where this claim stops

Measured on standard math and Python benchmarks, where Beam already scores about 97%. Harder problems may need more thinking: v0.2 tests frontier math (AIME 2026, HMMT 2026, Apex) and long-context state tracking. One provider (Baseten), one sample per cell, temperature 0.7. For your own traffic, run calibrate (next tab).

Wrap your client

from openai import OpenAI
from beamdial import BeamDial

beam = BeamDial(OpenAI(base_url="https://router.huggingface.co/v1", api_key=HF_TOKEN))
res = beam.create(messages=[{"role": "user", "content": prompt}])
print(res.effort, res.total_tokens, res.content)

# escalate only when your own check fails
res = beam.create(messages=msgs, verify=lambda text: my_tests_pass(text))

# re-ask at high when low thinks unusually long (no checker needed)
beam = BeamDial(client, policy="cascade", start="low", long_think_tokens=3000)

Measure the gap on your own prompts

Our benchmark is a starting point. calibrate runs your prompts at each level, tests whether the gap is real, and prints the cheapest setting that keeps your accuracy.

# my_prompts.jsonl: {"prompt": "...", "answer": "..."} per line
python -m beamdial calibrate my_prompts.jsonl --levels low,high,max --budget-usd 2
